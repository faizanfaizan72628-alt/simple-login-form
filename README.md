 #Simple Login Form 
A clean and beginner-friendly login form built using HTML, CSS, and JavaScript.
 #Features
- Email and password input fields
- Simple and responsive design
- Hover effect on the Login button
- Basic form submission message
 #Technologies Used
- HTML5
- CSS3
- JavaScript
 #How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
 #Note
This project is for learning purposes. It does not include real authentication or database integration.
